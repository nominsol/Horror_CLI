# 🏥 복도 끝의 병실

> 공포 컨셉의 텍스트 기반 CLI 어드벤처 게임

---

## 📖 게임 소개

새벽 3시, 당신은 정신병동에서 눈을 뜹니다.  
아무것도 기억나지 않는 채로, 어두운 병원을 탈출해야 합니다.

선택에 따라 결말이 달라지며, 숨겨진 비밀을 찾아내면 시크릿 엔딩을 볼 수 있습니다.

## 🎮 게임 플레이

텍스트로 출력되는 상황을 읽고, 번호를 입력하여 행동을 선택합니다.

```
>> 1
```

글자가 한 글자씩 타이핑되는 연출로 긴장감을 더합니다.

---

## 🗺️ 게임 구조

```
병실 (시작)
 └─► 복도
      ├─► 간호사실 ──► 복도 ──► 지하 계단 ──► 철문 (엔딩)
      └─► 지하 계단 ──► 철문 (엔딩)
```

### 장소 설명

| 장소 | 설명 |
|------|------|
| 🛏️ 병실 | 시작 장소. 단서와 힌트를 얻을 수 있다 |
| 🌑 복도 | 추적하는 귀신을 피해 나아가야 하는 어두운 복도 |
| 🖥️ 간호사실 | 열쇠를 획득할 수 있는 장소. CCTV를 확인하면 위험 |
| 🪜 지하 계단 | 출구로 향하는 중간 지점 |
| 🚪 철문 | 최종 출구. 아이템 보유 여부에 따라 엔딩이 결정됨 |

---

## 👻 등장 귀신

### 추적자 (StalkGhost)
복도에 등장하는 귀신. 플레이어가 앞으로 계속 나아가면 점점 거리가 좁혀져 결국 조우하게 됩니다.

### 302호 환자 (PatientGhost)
간호사실의 CCTV를 확인했을 때 등장하는 귀신. ASCII 아트로 섬뜩한 모습을 연출합니다.

---

## 🏆 엔딩

| 엔딩 | 조건 |
|------|------|
| 💀 배드 엔딩 | 열쇠 없이 철문에 도달 |
| ✅ 트루 엔딩 | 열쇠를 가지고 철문에 도달 |
| ⭐ 시크릿 엔딩 | 병실에서 힌트를 발견하고, 열쇠를 가지고 철문에 도달 |

## 🗂️ 프로젝트 구조

```
java/
├── Main.java               # 진입점
├── game/
│   ├── GameManager.java    # 게임 흐름 관리
│   ├── InputHandler.java   # 사용자 입력 처리
│   └── TextEffect.java     # 타이핑 텍스트 연출
├── entity/
│   ├── Ghost.java          # 귀신 기본 클래스
│   ├── StalkGhost.java     # 추적형 귀신
│   ├── PatientGhost.java   # 환자 귀신
│   └── Player.java         # 플레이어 상태 관리
└── scene/
    ├── Place.java          # 장소 기본 클래스
    ├── HospitalRoom.java   # 병실
    ├── Corridor.java       # 복도
    ├── NurseStation.java   # 간호사실
    ├── BasementStairs.java # 지하 계단
    └── FinalDoor.java      # 철문 (엔딩 분기)
```

## ⚙️ 실행 방법

### 요구 사항
- Java 11 이상

### 컴파일 및 실행

```bash
# 컴파일
javac -d out java/**/*.java java/Main.java

# 실행
java -cp out Main
```

---

## 🛠️ 기술 스택

- **언어**: Java
- **패턴**: 장소 간 이동을 `Place` 추상 클래스와 메서드 체이닝으로 구현
- **상속**: `Ghost` → `StalkGhost`, `PatientGhost` / `Place` → 각 장소 클래스
- **연출**: `TextEffect.type()`으로 글자 단위 타이핑 효과 (50ms 딜레이)
- **아이템**: `Player` 객체의 상태값(`hasKey`, `hasHint`, `isDie`)으로 엔딩 분기 관리
